# 贴片机 EQ-PICK-002 维护手册

> 设备绑定：EQ-PICK-002（设备绑定型 ASSET_BOUND）
> 适用车间：workshop:PCBA / line:SMT-1

## 概述
本手册适用于贴片机 EQ-PICK-002 的故障诊断与维护，含故障码对照与处置流程。

## 故障码 E101 吸嘴堵塞
现象：贴片机抛料率上升，吸嘴吸取失败报警。
原因：吸嘴孔堵塞 / 真空过滤堵塞 / 吸嘴磨损。
处置：
1. 停机，取下吸嘴用专用清洗针疏通。
2. 检查真空过滤器，堵塞则更换。
3. 目检吸嘴尖端磨损，磨损 >0.1mm 更换吸嘴。
4. 复测吸取，抛料率 <0.3% 恢复生产。

## 故障码 E102 视觉定位失败
现象：MARK 点识别失败，贴装偏移超差。
原因：光源亮度不足 / 相机镜头污染 / MARK 点氧化。
处置：
1. 调整环形光源亮度至 60%~80%。
2. 用无尘布清洁相机镜头。
3. MARK 点氧化时清洁 PCB 或更换批次。

## 保养周期
- 每班：清洁吸嘴、检查真空压力。
- 每周：校验视觉系统、更换真空过滤。
- 每月：导轨与伺服精度检测。
