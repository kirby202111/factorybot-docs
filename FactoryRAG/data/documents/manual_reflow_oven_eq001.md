# 回流焊炉 EQ-REFLOW-001 维修手册

> 设备绑定：EQ-REFLOW-001（设备绑定型 ASSET_BOUND）
> 适用车间：workshop:PCBA / line:SMT-1

## 概述
本手册适用于回流焊炉 EQ-REFLOW-001 的故障诊断与维修，含故障码对照与处置流程。

## 故障码 E001 加热区超温
现象：加热区实际温度超过设定值 10℃ 以上，设备报警停机。
原因：SSR 击穿 / 热电偶老化 / PID 参数漂移。
处置：
1. 停线，切断加热区电源。
2. 检查 SSR 是否击穿，击穿则更换 SSR 模块。
3. 校验热电偶，偏差 >3℃ 更换。
4. 重新整定 PID 参数，升温斜率回调 1~3℃/s。
5. 复测温度曲线，峰值温度稳定在 245±5℃ 后恢复生产。

## 故障码 E002 链速异常
现象：链速波动 >5%，或导轨卡顿。
原因：链条润滑不足 / 电机编码器故障 / 导轨异物。
处置：
1. 检查链条润滑，补充高温润滑脂。
2. 检查编码器接线，松动则紧固。
3. 清理导轨异物，复测链速稳定在 80cm/min。

## 保养周期
- 每班：清洁链夹、检查炉膛排风。
- 每周：校验热电偶、润滑链条。
- 每月：SSR 与电机绝缘检测。
