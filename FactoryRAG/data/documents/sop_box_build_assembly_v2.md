# 整机组装（Box Build）标准作业指导书（route v2）

> 工艺路线：route-box-build @ v2（工艺绑定型）
> 适用车间：workshop:BOX / line:FA-1

## 1. 目的
规范整机组装的螺丝锁附、接线、功能测试与老化作业，确保整机可靠性。

## 2. 工艺参数（v2）
- 螺丝扭矩：1.5±0.2 N·m（M3 螺丝）
- 螺丝扭矩：3.0±0.3 N·m（M4 螺丝）
- 老化温度：45±2℃
- 老化时长：4 小时
- 功能测试电压：DC 24V

## 3. 操作步骤
步骤1 装配：按 BOM 清点物料，外壳与 PCB 对位装入治具。
步骤2 螺丝锁附：使用电批按 v2 扭矩锁附，M3 螺丝扭矩 1.5±0.2 N·m，M4 螺丝扭矩 3.0±0.3 N·m，锁附顺序由内向外。
步骤3 接线：按接线图连接线束，确认到位卡扣锁紧。
步骤4 功能测试：DC 24V 上电，跑功能测试程序 5 分钟，各项 PASS 放行。
步骤5 老化：整机入老化房 45±2℃，老化 4 小时，期间监控无死机/重启。

## 4. 质量门
- 螺丝滑牙/浮高判 REJECT，缺陷码 BB-001（螺丝滑牙）
- 功能测试失败判 REJECT，缺陷码 BB-002（功能失效）
- 老化不良率 ≤200 ppm

## 5. 异常处置
扭矩异常或滑牙时，校验电批扭矩并复拧，记录批次追溯。
