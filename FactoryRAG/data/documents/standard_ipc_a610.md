# IPC-A-610 焊点质量验收标准

> 文档类别：通用知识型（GENERAL），无工艺版本绑定
> 适用：所有 PCBA 焊点外观验收

## 1. 目的
依据 IPC-A-610 标准，规定 SMT 与 THT 焊点的外观验收准则。

## 2. SMT 焊点验收
- 锡量：可接受 75%~95%，<50% 或 >100% 判不合格。
- 焊点爬锡高度：≥1/4 焊盘宽度为合格，<1/4 判少锡。
- 焊点形态：光亮饱满、无拉尖，拉尖长度 >0.3mm 判不合格。
- 位置偏移：≤0.05mm 为合格，>0.1mm 判不合格。

## 3. 典型缺陷判定
- 锡桥（缺陷码 SW-001）：焊盘间连锡，判 REJECT。
- 立碑（缺陷码 SW-002）：元件一端翘起，判 REJECT。
- 少锡（缺陷码 SW-003）：焊点爬锡高度 <1/4，判 REJECT。
- 冷焊（缺陷码 SW-004）：焊点表面暗淡无光泽，判 REJECT。

## 4. 验收抽样
- AQL 抽样：每批 100% AOI + 人工复核 5%。
- 缺陷率统计：锡桥、立碑、少锡、冷焊分类统计 ppm。

## 5. 复判流程
AOI 判 REJECT 的焊点由复判员按本标准人工复核，复判 PASS 放行，REJECT 转返工。
