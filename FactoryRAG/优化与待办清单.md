## 🔴 P0 - 生产风险 & 架构穿透

### [ ] 1. httpx.AsyncClient 资源泄漏(L1/L2 委托客户端未关闭)
- **位置**:`app/routes/agentic/__init__.py:53-54`
- **问题**:E 路线装配时创建 `l1_http`/`l2_http` 两个 `httpx.AsyncClient`,既不存入 container 也不在 `Container.dispose()` 中 `aclose()`,连接池泄漏。
- **建议**:将两个 client 存入 container 实例属性,`dispose()` 一并关闭。

### [ ] 2. MES base URL 硬编码,不可配置
- **位置**:`app/shared/web/container.py:47`
- **问题**:`mes_base_url="http://mes:8080"` 写死,`RagSettings` 无 MES 配置项,dev/staging/prod 无法切换。
- **建议**:`BaseSettings` 增 `MesSettings(base_url)`,从 `RAG_MES__BASE_URL` 注入。

### [ ] 3. router 穿透 application 层访问私有属性
- **位置**:`app/api/v1/chat_router.py:30`
- **问题**:`/agent/explain/{audit_id}` 直接调 `svc._audit_repo.find_by_id(audit_id)`,绕过 GatewayService 公开接口,router 知晓了 service 内部结构。
- **建议**:GatewayService 暴露 `async def explain(audit_id) -> AnswerAuditView`,router 经它取数。

### [ ] 4. ConsumerGroup 逐条 commit + Kafka/MySQL 双提交不一致
- **位置**:`app/shared/kafka/consumer_group.py:104-105`
- **问题**:每条消息处理后立即 `commit()`;且 Kafka commit 与 `_process` 内 MySQL 幂等事务是两条路径——commit 成功但事务失败时消息丢失。
- **建议**:改按时间窗口/批量 commit;或将 offset 提交纳入 MySQL 事务(outbox/两阶段)。

### [ ] 5. agentic 路线零集成测试
- **位置**:`tests/`(无 GatewayService/IntentRouter/ToolExecutor/SubAgentDelegator 测试)
- **问题**:`test_route_graph.py` 仅覆盖 LangGraph 不可用时的 `_FallbackGraph` 降级,正常路径/L1L2 委托超时/工具链汇聚全未测。E 路线是新增,等于裸奔。
- **建议**:补 `GatewayService.chat` 三意图分支(TRACE_FACT/DOC_LOOKUP/ROOT_CAUSE)端到端 mock 测试。

## 🟡 P1 - 检索与生成质量

### [ ] 6. 子图缓存未命中仍每次写 MySQL
- **位置**:`app/routes/traceability/application/trace_retrieval_service.py:80-89`
- **问题**:`_expand` 每次缓存未命中都 `subgraph_repo.save`,写入频率与检索 QPS 正比,MySQL 易成瓶颈;子图持久化应为可选而非默认写路径。
- **建议**:改 fire-and-forget 或按采样(仅持久化转人工低置信案例),或配置开关。

### [ ] 7. LLM 响应缺整体 schema 校验,畸形输出静默降级
- **位置**:`app/routes/traceability/application/trace_retrieval_service.py:118`
- **问题**:仅对 `hypotheses` 做 `model_validate`,`summary`/`confidence` 裸 `data.get()`+`float()`,LLM 返回畸形 confidence(如字符串)抛 ValueError 被外层 except 吞掉静默降级。
- **建议**:定义完整 `LlmTraceOutput` Pydantic 模型,`model_validate(data)` 一次性校验。

### [ ] 8. B 路线置信度固定 0.75,永不因质量触发人工复核
- **位置**:`app/routes/document/application/retrieval_service.py:162`
- **问题**:`confidence = 0.75` 硬编码,`needs_human_review` 仅在无 citations 时触发,与 A 路线(LLM 自评 confidence)不一致。
- **建议**:至少让 LLM 在 prompt 输出置信度自评,或接忠实度评测(faithfulness)。

### [ ] 9. `_materialize` 脆弱 duck-typing 分派 tool_result
- **位置**:`app/routes/agentic/application/gateway_service.py:142`
- **问题**:`tool_result` 可能是 TraceSubgraph/list[ChunkHit]/L1L2 dict 三类,用 `getattr`+`str()[:200]` 分派;新增路线类型易遗漏,`str(list[ChunkHit])[:200]` 输出不可读 repr。
- **建议**:为各 tool_result 类型定义 `materialize()` Protocol,或按已知 `intent` 用 match/case 显式分派。

## 🟢 P2 - 工程化打磨

### [ ] 10. deps.py 五个 get_*_svc 重复 None 检查
- **位置**:`app/api/deps.py:16-28`
- **问题**:五个依赖函数结构完全相同(检查 `container._xxx is None` -> 抛 503),典型重复。
- **建议**:提取 `_get_svc(container, attr, route_name)` 工厂。

### [ ] 11. Agentic 路线配置分散在两个 settings 类
- **位置**:`app/shared/config/rag_settings.py:42-43`(AgenticSettings) + `app/shared/config/base.py`(AgentSettings)
- **问题**:`AgenticSettings` 只有 enabled/cache_ttl,L1L2 URL/超时在 `AgentSettings`;后者未嵌在 `rag.agentic` 下,配置结构不直观。
- **建议**:合并 `AgentSettings` 入 `AgenticSettings`,或嵌套到 `rag.agentic` 命名空间。

### [ ] 12. lifespan 非标准三参签名
- **位置**:`app/shared/web/lifespan.py:21` + `app/main.py:25-28`
- **问题**:`lifespan(app, settings, container)` 三参,需 main.py 闭包适配;settings/container 已挂 `app.state`,可内部取值。
- **建议**:改标准 `lifespan(app)`,内部从 `app.state` 取 settings/container。

### [ ] 13. ingestion tenant_scope 静默取首个 scope
- **位置**:`app/routes/document/application/ingestion_service.py:79`
- **问题**:`tenant.tenant_scopes[0] if ... else cmd.tenant_scope`,多 scope 租户只取第一个,其余静默丢弃,影响检索租户过滤精度。
- **建议**:持久化全部 scope,或显式记录丢弃告警。

### [ ] 14. `_FallbackGraph.ainvoke` 忽略 config 参数
- **位置**:`app/routes/agentic/infrastructure/ai/route_graph_builder.py:86`
- **问题**:接收 `config` 但不用,`recursion_limit` 等被忽略,接口契约不一致。
- **建议**:降级场景至少尊重关键 config,或在签名上标明忽略。

### [ ] 15. chat_router 函数内 lazy import HTTPException
- **位置**:`app/api/v1/chat_router.py:32`
- **问题**:`from fastapi import HTTPException` 在函数内,文件顶部已 import FastAPI 符号,无必要 lazy。
- **建议**:移到顶部 import。
