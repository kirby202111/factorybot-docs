# 简历 · 核心贡献

> 面向 5 年经验后端开发岗位。基于 `领域模型/` 与 `实现说明/` 文档（不含 Agent/RAG 旁路部分）撰写，按**架构设计与实现 / 性能优化 / 高可靠保障**三个维度组织。
> 量化数据为按后端系统常见量级编造的示例值（与项目设计容量目标同量级），使用时可按真实压测/监控数据替换。

---

## 项目背景（一行锚点）

主导面向 PCBA 电子制造 + 整机组装混合型车间的 MES 系统后端建设：基于事件风暴 + DDD 拆分为 3 个微服务、14 个限界上下文，以 Kafka 为跨服务事件骨干，覆盖工单、过点执行、设备采集与运维全链路。

---

## 核心贡献

### 一、架构设计与实现

**主导 MES 后端 DDD 领域建模与事件驱动架构落地，构建零分布式事务的跨服务协作骨架**

- **技术动作**：基于事件风暴将混合型车间 MES 拆分为 3 个微服务、14 个限界上下文，建立三段式不变式体系（聚合内强一致 INV / 上下文内最终一致 BIZ / 跨上下文最终一致 INV-CX）分层治理一致性边界；设计 Transactional Outbox + Kafka 事件骨干——业务状态与事件记录同库事务原子投递、`partition_key=聚合根ID` 分区保序、幂等 Producer，13 个业务语义化 topic 命名空间承载近百个领域事件，并以四层限流（领取节流 / 全局令牌桶 / 按 topic 公平 / 在途上限）作为架构级流量控制点；过点执行引擎将过点记录、放行决策、路线推进、工单进度、测试结果五聚合收敛至同一本地事务，配合上下文内 CQRS 写读分离；架构级区分高频采集与低频业务事件双链路，从根上避免两类流量互相拖累。
- **量化效果**：跨服务协作零分布式事务，过点主事务仅写本地 DB；事件契约覆盖 14 个上下文的全部跨域协作场景；上下文边界调整引发的回归缺陷较早期单体式方案下降约 70%，新限界上下文接入周期从约 2 周缩短至 3 天。
- **业务影响**：将混合型车间的业务复杂度拆解为边界清晰、可独立演进的上下文，支撑工单下达→过点→完工跨 6+ 上下文的长链路流程，服务可独立发布、互不阻塞。

### 二、性能优化

**负责高并发采集链路与过点执行链路的性能设计与调优，达成万级吞吐与毫秒级响应**

- **技术动作**：采集链路在边缘网关完成协议解码与攒批发送，大载荷（扭矩曲线 / AOI 图像 / 烧录日志）经预签名 PUT 直传 MinIO、主流仅传 URI + sha256，平台侧 `msg_id` 去重 + 乱序矫正，存储按热（Redis 实时快照）/ 温（MySQL）/ 冷（对象存储）三层分流；过点链路将工艺路线、设备可用性、质量门禁、齐套四类写少读多的配置数据本地缓存化，缓存未命中才降级 REST 查询权威源；齐套状态多源事件重算引入去抖合并，同工单事件按分区保序串行处理，避免乐观锁冲突雪崩。
- **量化效果**：采集吞吐峰值 1.2 万报文/秒、端到端落库延迟 P99 < 1s；大载荷分流使 Kafka 主流流量下降约 70%；过点全链路 P99 ≤ 200ms（缓存命中主路径）、降级查询 ≤ 500ms，配置缓存命中率 > 99%，换班高峰 50 工位并发扫码无超时与缓存雪崩；批量 BOM 导入场景齐套重算次数下降约 90%；资产可用性状态查询 QPS 2000+、P99 < 20ms。
- **业务影响**：秒级工艺参数与单件事件实时可靠入库，过点响应满足产线节拍要求，采集高峰与过点高峰互不挤压，产线不停线。

### 三、高可靠保障

**建设消息、采集、业务三层可靠性体系，实现崩溃零丢失与业务级防错闭环**

- **技术动作**：消息层以 Outbox 状态机（PENDING→PUBLISHING→SENT，失败 RETRYABLE，重试耗尽 DEAD_LETTER）保障至少一次投递，消费端 `event_id` 幂等且幂等记录与业务处理同事务提交，DLT 死信保留原始报文支持人工修复后重放；采集层以边缘缓冲 + 断点续传（单调游标"先补后新"）应对网关断网，平台 `msg_id` 去重 + 乱序矫正窗口吸收补传乱序；业务层构建设备可用性 9 维阻塞投影合取重算（任一维度阻塞即不可用、全部解除才恢复），同服务强防错场景走本地事务同步、跨服务走异步事件，并以工单产品流水号等量预发 + 首工序绑号过点实现超产物理门禁，状态机终态拒收一切非法流转。
- **量化效果**：事件投递成功率 99.99%、宕机恢复场景消息丢失为 0、消费重复处理率 < 0.01%；网关断网 30 分钟恢复后采集数据零丢失、补传去重命中率 99.9%；可用性重算幂等率 100%（并发/重复事件零副作用）、CRITICAL 故障停机同步延迟 < 50ms；工单超产拦截率 100%、非法状态流转拦截率 100%。
- **业务影响**：跨 6+ 上下文的长链路业务流在宕机、断网、突发流量下不断裂、不重复；带病/超期设备无法流入生产，超产与错版投产从源头杜绝，满足汽车电子级审计追溯要求。
