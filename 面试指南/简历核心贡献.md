## 项目背景

主导面向 PCBA 电子制造 + 整机组装混合型车间的 MES 系统后端建设，覆盖工单、过点执行、设备采集与运维全链路。

---

## 核心贡献

### 一、架构设计与实现

- **领域建模与服务拆分**：基于事件风暴按变化频率、一致性边界与视角分离，将 MES 拆分为制造资源、设备管理、生产执行 3 个微服务（14 个限界上下文），以三段式不变式体系分层治理一致性边界，上下文回归缺陷较单体式方案下降约 70%，新上下文接入周期从 2 周缩短至 3 天。
- **Outbox 事件骨干**：设计业务状态与事件同库事务原子投递机制，聚合根 ID 分区保序 + 幂等 Producer，13 个语义化 topic 承载近百个领域事件，四层限流（领取节流 / 全局令牌桶 / 按 topic 公平调度 / 在途上限）稳定兜住 2000+ 事件/分钟突发流量，物料多源事件驱动的齐套重算引入去抖合并、批量 BOM 导入场景重算次数下降约 90%，实现跨服务协作零分布式事务，支撑工单下达→过点→完工跨 6+ 上下文长链路异步解耦。

### 二、性能优化

- **高并发采集链路**：通过边缘网关协议解码攒批、大载荷（扭矩曲线/AOI 图像/烧录日志）预签名直传 MinIO 仅传 URI 引用、热温冷三层存储分流，实现峰值 1.2 万报文/秒、落库延迟 P99 < 1s，Kafka 主流流量下降约 70%，秒级工艺参数实时入库支撑 SPC 分析与全链路追溯。
- **过点全链路优化（写侧原子事务 + 读侧低延迟）**：写侧将过点记录、放行决策、路线推进、工单进度、测试结果五聚合同事务原子提交（主事务仅写本地 DB），配合上下文内 CQRS 写读分离与采集/业务双链路架构级分流，使“过站瞬间”成为不受高频采集冲击的原子业务事实；读侧工艺版本与物料/工装按工单下达时绑定的不可变版本快照读取，从机制上消除配置缓存一致性窗口，设备可用性、质量门禁、齐套状态等实时状态投影本地缓存化并以降级 REST 兜底，实现过点全链路 P99 ≤ 200ms、缓存命中率 > 99%，换班高峰 50 工位并发扫码无超时雪崩。

### 三、高可靠保障

- **消息可靠投递**：以 Outbox 状态机 + 指数退避 + DLT 死信可修复重放保障至少一次投递，消费端 event_id 幂等且与业务处理同事务，事件投递成功率 99.99%、宕机恢复场景零丢失、重复处理率 < 0.01%，长链路业务流在宕机下不断裂、不重复。
- **采集断连韧性**：以边缘缓冲 + 断点续传（单调游标“先补后新”）+ 平台 msg_id 去重与乱序矫正应对网络抖动，网关断网 30 分钟恢复后采集数据零丢失、补传去重命中率 99.9%。
- **业务级防错**：构建设备可用性 9 维阻塞合取重算（重算幂等率 100%）、CRITICAL 故障同事务同步停机（延迟 < 50ms）、工单产品流水号等量预发实现超产物理门禁（拦截率 100%）与状态机终态拒收，从源头杜绝带病设备流入生产与超产错版投产。
